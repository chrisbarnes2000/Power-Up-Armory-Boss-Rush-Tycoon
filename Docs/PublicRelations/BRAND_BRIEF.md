## 6. Dislikes, Opponents & Anti-Patterns

### Practices We Strictly Oppose
* **Predatory Gacha & Dark Patterns**: Hidden odds, expiring artificial currencies, and pay-to-win progression gates.
* **Intrusive Interstitial Ads**: Forced 30-second popups interrupting gameplay or combat turns.
* **Bloated Mobile Layouts**: Unresponsive web UIs that clip combat healthbars or require horizontal panning on mobile devices.
* **Unbounded Memory Leaks**: Sloppy listener lifecycles that degrade frame rates after extended play sessions.

### Competitive Matrix
| Feature / Paradigm | Generic Mobile/Web Tycoon | PowerUp Boss Tycoon |
| :--- | :--- | :--- |
| **Monetization** | Pay-to-win paywalls, forced ads | Pure gameplay progression, optional receipt keys |
| **Combat Depth** | Coin flip / simple stat check | Turn-based mechanics, weakness multipliers, kill/death streak boosts |
| **Code Quality** | Opaque, bloated scripts | NASA JPL Rule 10 audited, modular subcomponents, zero lint warnings |
| **Accessibility** | Fixed rigid font sizes | Dynamic 50%–165% font scaling & WCAG 2.1 AA high contrast |
| **Persistence** | Local-only or unreliable sync | Dual local storage + Firestore auto-sync with conflict resolution |
