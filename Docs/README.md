# RapportVerse & Power-Up Armory Developer Documentation

RapportVerse and Power-Up Armory bring together high-performance qualitative relationship mapping, gamified commerce, and real-time arcade tycoon RPG systems. 

## Project Structure
- `/src/components`: UI views including ShopView, GameView, LoreBookView, AdminModal, AccountModal, GuidedTour, and Footer.
- `/src/lib`: Core client modules, including Firebase Auth and Firestore integration.
- `/public`: Static web assets, PWA manifest (`site.webmanifest`), favicons, robots.txt, llms.txt, and 400/404/500 error pages.
- `/Docs`: Technical references for developers, designers, brand strategists, and system integrators.
  - `/Docs/Agent_Instructions`: Mandatory operating procedures, NASA JPL Power of 10 safety rules, ITIL v4 governance, and Agile ceremonies.
  - `/Docs/LoreBook`: In-game compendium, boss chronicles, item catalogs, and realm system lorebooks.
  - `/Docs/PublicRelations`: Brand brief, ecosystem partnership assets, and strategic marketing guides.
